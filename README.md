# Arrem@ta Bov

Protótipo v1 do Arrem@ta Bov: compra e venda de lotes de gado comercial com o corretor no centro do negócio, que fecha dentro do app.

Página estática (index.html + app.css + app.js + dados.js), sem build. Lotes, pessoas, preços, Pix, contrato e assinatura são de exemplo. Taxa do app (0,15% por lado), sinal (5%), taxa de visita (R$ 150) e lote mínimo (30 cabeças) são propostas a validar.

Testar local: `python -m http.server 8766` nesta pasta e abrir http://localhost:8766/
